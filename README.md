# Room Nine · ရုံးခန်း ဆူပူ

CSMC marketing ရုံးခန်းကို 3D နဲ့ ဆောက်ထားတဲ့ browser game။ Three.js သုံးထားပြီး file တစ်ခုတည်းနဲ့ run တယ်။

**Play:** https://gwanti-dev.github.io/room-nine/

## ဆော့နည်း
| Key | လုပ်ဆောင်ချက် |
|---|---|
| W A S D | လမ်းလျှောက် |
| E | ဘာလုပ်နေလဲ ကြည့် |
| F | စက္ကူလိပ်နဲ့ ခေါက် |
| G | Laptop လုယူပြီး ပြေး (၂ စက္ကန့် ကြိုပြေးခွင့်၊ ၂၂ စက္ကန့် မမိရင် နိုင်) |
| Q | Meeting ခေါ် |
| V | View ပြောင်း (Overview · Follow · Photo angle · Top · First person) |

ဖုန်းမှာ joystick နဲ့ ခလုတ်တွေနဲ့ ဆော့လို့ရတယ်။

## Online ဆော့နည်း
1. တစ်ယောက်က ကိုယ့်နာမည်ရွေးပြီး **Room အသစ်ဖွင့်မယ်** နှိပ်ပါ · Room code ၄ လုံး ရမယ်
2. **Invite link copy ကူးမယ်** နှိပ်ပြီး team group ထဲ ပို့ပါ
3. ကျန်တဲ့သူတွေ link ဖွင့်၊ ကိုယ့်နာမည်ရွေး၊ **Join** နှိပ်ပါ

Host က tab ပိတ်လိုက်ရင် room ပိတ်သွားမယ်။ Network တချို့မှာ ချိတ်မရရင် wifi ပြောင်းပြီး စမ်းပါ။
